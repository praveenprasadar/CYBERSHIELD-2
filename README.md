
AI-Based Cyber Safety & Phishing Detection Platform

Project Overview
1.The AI-Based Cyber Safety Platform is designed to protect users from online threats such as phishing attacks, scam messages, harassment, and data theft. With the rapid growth of digital communication, cybercriminals use deceptive messages, fake websites, and social engineering techniques to steal personal and financial information.
2.This project uses Machine Learning and Artificial Intelligence to analyze URLs, messages, and screenshots to detect potential cyber threats. The system provides users with clear explanations, risk levels, and safety recommendations to help them make secure decisions while interacting online.
3.The platform also focuses on women’s cyber safety, identifying harassment patterns, stalking behavior, and emotionally manipulative scams that commonly target women.

Objectives
1.The main objective of this project is to develop an intelligent cyber safety assistant that can:
2.Detect phishing websites and malicious URLs
3.Identify scam messages and fraudulent communications
4.Analyze screenshots using OCR to detect hidden threats
5.Provide explainable AI insights for better user understanding
6.Offer safety suggestions to prevent cybercrime

Key Features
1. Phishing URL Detection

  The system uses a machine learning model trained on phishing datasets to detect malicious URLs. It analyzes patterns such as suspicious domains, brand impersonation, and unusual link structures.
  Users can input any URL into the system, and the model predicts whether the link is safe or phishing, along with a confidence score and risk level.

2. Message & Email Scam Detection

     Users can paste suspicious SMS messages, emails, or chat messages into the platform.
     The AI analyzes the text to detect common scam patterns including:
     OTP scams
     Fake bank alerts
      Job scams
      Prize scams
      Impersonation fraud
      The system highlights suspicious keywords and provides a clear explanation of the risk.

3. Screenshot Analysis Using OCR

       Many scams are shared through screenshots on messaging apps or social media.
       The system includes OCR (Optical Character Recognition) to extract text from uploaded images. After extracting the text, the AI analyzes the content to detect possible scams or phishing attempts.
       This allows users to identify threats even when the scam appears in image format.

4. Women-Focused Cyber Safety Features

    The platform includes features specifically designed to protect women from online harassment and exploitation.
    It can detect:
    Harassment and threatening language
    Cyberstalking behavior
    Emotional manipulation scams
    Romance scams targeting women
    This helps users identify potentially dangerous online interactions and take preventive action.

5. Explainable AI Detection
    Instead of only providing a simple prediction, the system also explains why a message or URL is suspicious.

The output includes:
    Prediction result (Safe / Scam / Phishing)
    Risk level (Low / Medium / High)
    Confidence score
    Detailed explanation of detected risk factors
    This transparency helps users understand cyber threats more clearly.

7. Emergency Safety Suggestions
     when a high-risk threat is detected, the platform provides instant safety recommendations, such as:
     Avoid clicking suspicious links
     Do not share OTP or personal details
     Block and report suspicious contacts
     Contact the official service provider for verification
     These suggestions help users respond quickly to potential cyber threats.

System Workflow

    The user submits a URL, message, or screenshot to the system.
    The backend processes the input and sends it to the AI model.
    The machine learning model analyzes the input for suspicious patterns.
    The system generates a prediction with risk level and explanation.
    The results are displayed in the user interface along with safety suggestions.
